# User Testing

## Key Findings

### Accessibility
Test users highlighted limited internet access in remote areas as a potential barrier.

**Proposed response:** Introduce offline access to selected educational materials, FAQs, and basic HIV/STI information.

### Security and Privacy
Test users expressed concern about unauthorized access and data breaches that could expose sensitive health information.

**Proposed response:** Apply strong security measures and data minimization, collecting and storing only information required for the application's functions.

### Communication
Test users identified delays in communicating test results, appointments, and updates as a source of uncertainty and anxiety.

**Proposed response:** Integrate secure communication between users and healthcare providers.

## Iterative Testing

The project proposes continued testing with diverse user groups to identify issues, gather feedback, and refine platform design and functionality iteratively.
