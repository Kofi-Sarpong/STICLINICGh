# Solution Overview

STICLINICGh is a comprehensive mobile application designed to empower Ghanaians with accessible and confidential sexual-health information, testing, counselling, and support.

## Core Features

### STI/HIV Information
Provides accessible sexual-health information and guidance.

### Clinic Directory
Helps users identify relevant STI/HIV healthcare facilities.

### Online Counselling
Provides a pathway for users to seek counselling and support.

### Appointment Booking
Allows users to schedule healthcare appointments.

### User Account
The prototype includes sign-up, login, password reset, home, and profile screens.

### Appointment Management
The prototype includes client information, scheduling, and confirmation screens.

## User Flow

**Authentication → Home → Information / Find Clinic / Counselling → Appointment → Client Information → Schedule → Confirmation**

## Design Focus

- Accessibility
- Confidentiality
- User-centered access to information
- Simplified navigation to services
- Privacy-conscious handling of sensitive information
- Integration of information and service access

## Intended Impact

The solution aims to reduce practical barriers to sexual-health engagement by connecting users with information, counselling, healthcare facilities, and appointment services through one digital platform.
